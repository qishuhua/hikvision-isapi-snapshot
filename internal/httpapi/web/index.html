立即截图 API

所有业务 API 使用 HTTP Basic 管理员认证。返回 image/jpeg，可直接写入文件。upload=true 表示截图后同时上传 OSS。

传入临时摄像机参数，不落库

curl -u "$ADMIN_USER:$ADMIN_PASSWORD" -X POST 'https://your-host/api/capture' \
  -H 'Content-Type: application/json' \
  -d '{
    "base_url":"http://192.168.1.10",
    "username":"admin",
    "password":"replace-me",
    "channel_id":"201",
    "endpoint_mode":"proxy",
    "upload":false
  }' --output snapshot.jpg

使用已配置摄像机

curl -u "$ADMIN_USER:$ADMIN_PASSWORD" -X POST \
  'https://your-host/api/cameras/{camera_id}/capture?upload=true' \
  --dump-header headers.txt --output snapshot.jpg
# 成功后响应头 X-OSS-Object-Key 保存 OSS 对象路径

其他 REST 接口

GET    /api/health                      健康检查（免登录）
GET    /api/cameras                     摄像机列表
POST   /api/cameras                     新增摄像机
PUT    /api/cameras/{id}                修改摄像机
DELETE /api/cameras/{id}                删除摄像机及其计划
GET    /api/schedules                   计划列表
POST   /api/schedules                   新增计划
PUT    /api/schedules/{id}              修改计划
DELETE /api/schedules/{id}              删除计划
POST   /api/schedules/{id}/run          立即执行并上传 OSS
GET    /api/storage                     S3 配置（不返回秘钥）
PUT    /api/storage                     保存 S3 配置
GET    /api/records?limit=100           最近执行日志
